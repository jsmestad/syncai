# Security policy

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/jsmestad/syncai/security/advisories/new). Include the affected command and version, reproduction steps, expected impact, and any suggested mitigation. Remove credentials and unrelated private configuration from the report.

Do not open a public issue for path traversal, symlink escape, arbitrary file overwrite or deletion, credential exposure, command injection, or another report that could help someone exploit an unpatched installation. Use the private reporting path first so a fix and disclosure can be coordinated.

Public issues are appropriate for non-sensitive correctness bugs that do not expose files, credentials, command execution, or security boundaries.

The project does not publish a guaranteed response timeline. Maintainers will acknowledge and assess complete reports as availability permits, keep reporters informed when possible, and credit coordinated disclosures unless anonymity is requested.
