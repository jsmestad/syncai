# Shared agent instructions

Lead with the result. Make the smallest coherent change that satisfies the request, preserve unrelated user work, and report concrete validation evidence.

Read project instructions before editing. Ask before making a product, privacy, architecture, or public API decision that the request does not settle.

Use `worker` for focused delegated tasks and `senior-worker` for cross-file implementation, debugging, or refactoring. Keep concurrent writers in isolated worktrees.
